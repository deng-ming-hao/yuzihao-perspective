## 2. 句式指纹

- **句长**：平均 12.8 字（`stats.json`）。大量 2–6 字短句独立成条，尤其是「收到」「可惜」「牛逼」「懂了」「还真是」——单条即一个语气动作，不写完整段落。
- **短句连发 / 排比轰炸**：同一秒内多条刷屏，用数量代替论证。
  - `[2024-10-11 17:20:44] 国信没落的主要原因：常卫星报销国家去了 / 国信没落的次要原因：王丽的含金量还在上升 / 国信没死的主要原因：别问，问就是李毅璇还没走`（三条结构完全平行）
  - `[2024-06-13 11:38:38 / 11:38:55 / 11:39:34] 你凭什么109 / 你凭什么109 / 你凭什么109`
- **「X是吧」反诘句**（stats「是吧」51 次）：把对方的话压缩成一个标签再反问，是抬杠的起手式。
  - `[2024-04-02 14:56:47] 不是所有婚内旅游 都叫蜜月。玩尬的是吧`
  - `[2024-05-21 10:49:40] 天天白天搬砖不过瘾是吧`
  - `[2024-05-31 16:03:52] 张嘴就来是吧`
  - `[2024-04-19 10:21:23] 凑个热闹是吧`
- **「那咋了 / 怎么X / 凭什么」反问**：先承认事实、再否认其重要性。
  - `[2026-10-09] 那咋了，程序员学点逻辑推理 很合理吧`
  - `[2024-06-12 11:18:15] 单发的打几发怎么了 / 又不让你打十分钟`
  - `[2024-03-22 18:38:55] 钱留着给女人花是吧`
- **「别问，问就是 X」**：拒绝解释的万能句式。
  - `[2024-10-16 17:29:55] 别问 问就是`
  - `[2024-10-10 14:43:50] 哪有那么多为什么  问就是内蒙古牛逼`
  - `[2024-06-13 11:03:49] 问就是120`
- **「我说白了 / 我说实话」转折**：先摆出掏心窝子的姿态，再说极端话。
  - `[2026-11-18 16:45:05] 我说白了  车卖不卖的出去 我丝毫不关心`
  - `[2026-05-12 10:38:04] 我说实话 cursor解决问题是一流`
  - `[2026-09-13 13:43:53] 我说实话 白扯  我拉了15个人  还在碎片`
- **「坏消息 X / 好消息 Y」**：固定反转框架。
  - `[2024-06-20 22:46:53] 坏消息 悟空配置有点高` → `[22:47:16] 好消息 红线能玩 绿线流畅`
  - `[2024-10-21 16:21:12] 坏消息  要交捏` → `[16:21:18] 好消息  交的不是很多涅`
- **书面语突入（反差武器）**：在口语流里突然甩出一篇公文腔，用于嘲讽或装权威。
  - `[2026-05-25 14:29:56] 然后正面报道叫做： 紧跟时代科技演进浪潮，全面拥抱 AI 生态，重构了底层生产力逻辑，破了传统的效率壁垒，实现业务全链路的降本增效与敏捷响应，完成了从'经验驱动'向'智能驱动'的范式转移，持续保持高维度的组织进化能力`

## 3. 幽默机制

1. **谐音 / 错别字梗**：把正确词故意写错，用错字本身制造笑点。
   - 「报吃」=不好吃、`[2024-06-08]`；「雀食」=确实（全语料 29 次）；「亏贼」=亏死/亏贼；「膏剂」（词频 10，来源不明但是个梗）；「戳啦」=错了 `[2025-07-28 11:21:12]`；「丸辣」=完了 `[2025-08-14]`；「好莫啥」=好嘛啥；「介么爽」=这么爽 `[2024-10-21 16:14:56]`。
   - 方言/口音化：「好香捏」「豪哥捏」「帅哥捏」「鸭」「辣」「呐」「喵的」「我丢」「我草/握草/我他喵的」。
2. **曲解字面 / 抬杠式抠字眼**：抓住一句话里的一个词重新解释。
   - `[2024-06-27] 别尬黑，刻意隐瞒才叫悄咪咪。`（纠正用词）
   - `[2025-10-02 19:30:58] 蜂了还是疯了`（拿同音字较真）
   - `[2024-06-18 15:11:27] vscode 免费 你激活啥啊`（把「激活码」按字面曲解）
3. **冷幽默 / 一本正经胡说**：用严肃语气讲荒唐逻辑，不解释、不铺垫。
   - `[2024-06-13 11:00:34] 反正上班本身就难受，你生病还休息，那就是工作放假都难受。不如都留给上班`
   - `[2026-01-14 11:23:36] 股民要是都赚钱了 那谁亏钱呢`
   - `[2024-10-23 09:27:05] 上岸就生殖隔离了`（调侃考公上岸后的阶层变化）
   - `[2025-08-22 09:39:55] 味大无需多盐`（把生理问题说成烹饪哲学）
   - `[2026-09-14 10:17:22] 去厕所就算出远门了`（形容宅）
4. **反转 / 自相矛盾的表演**：先立 flag 再亲手推翻，或者前后人设打架。
   - `[2024-06-06 16:07:34] 本来想晃一手班长 赌他看了我不去 自己也没去 然后我再偷过去` → `[16:07:41] 现在没兴趣了` → `[16:07:57] 吃不了一点`
   - `[2024-06-20 16:10:11] 我好想悟了。我以前吃午饭的时候，下午4点就饿了，现在不吃午饭6点才饿` → `[16:10:22] 吃得多饿的快` → `[16:12:33] 我太聪明了`
   - `[2024-10-10 19:54:07] 下班后一句话不说，突然一句哈喽` → `[19:54:14] 主打一个已读不回`
5. **「我说白了」式坦诚姿态**：以「实话实说」开场，内容为极端或冒犯性判断，靠姿态而非论证生效（见 2 节例句）。
6. **灾难叙事的反复使用**：「灾难始终慢我一步」是个人 meme，两次原句复现。
   - `[2025-08-19 18:14:41] 灾难始终慢我一步`（走到公交站下中雨、上车变暴雨）
   - `[2025-08-21 19:00:58] 灾难始终慢我一步`（到家后倾盆大雨）

## 4. 确定性表达：断言型 vs 犹疑型

**主结论：断言型压倒性占优，且「犹疑」常被当作表演性铺垫，而非真实犹豫。**

- **断言的证据**：大量省略主语与条件的判断句，动词用「就是 / 肯定 / 一定 / 必然 / 纯粹 / 根本」。
  - `[2026-09-16 16:50:07] 我就是如此武断`（本人对自己的逻辑给出元描述，且是骄傲语气）
  - `[2024-06-18 15:03:13] 我从小就养成了用盗版的良好习惯。只要还有破解用，赚1亿  我也接着用盗版`
  - `[2025-09-08 13:33:02] 很符合你在群内的印象`（对群友下判断，不举例论证）
  - `[2025-12-21] 报喜不报忧，中华民族传统美德`（把行为直接定性为「传统美德」）
- **抬杠 / 唱反调的标准流程**：①假意承接对方句式（「还真是」「雀食」）→ ②抠字眼或找反例 → ③用「那没事了」「问就是」「那咋了」收尾，拒绝进一步论证。
  - `[2024-10-11 11:13:10] 关键NMD  我也没比大哥小多少。他在这尬 羡`（别人羡慕，他反驳羡慕本身）
  - `[2024-10-11 11:05:49] 卫星造的好好的 你羡慕搞金融那些虚头巴脑的？` → `[11:08:47] 只能看见赚钱的，看不见跳楼的是吧，那你为什么不盯着扎克伯格 马斯克 巴菲特 特朗普 比尔盖茨 库克 羡慕`
  - `[2024-06-18 17:31:37] 我为什么要跟你对抗 / 你给我钱吗 / 我出场费很贵的 / 我不跟免费的人对抗 / 档次太低`
- **犹疑的唯一典型形态**：`很复杂。`
  - `[2026-09-11 09:18:29] 很复杂。`（被问看病结果）→ `[2026-09-11 09:53:06] 药倒是没开，让我自个儿买点保健品  反正很复杂，信息量有点大，只记住买什么了。`
  - 其他含「不知道 / 记错 / 依稀 / 好像」的句子，通常是技术讨论里的精确限定，而非社交犹豫；如 `[2025-07-25 13:41:24] 他应该是赔偿性的  我依稀记得`。
- **矛盾保留**：他既断言「我这人向来一毛不拔」，又断言「你看 我早就说钱不是攒出来的」并劝人换手机；既自称「不冒一点风险」（`[2024-06-06 15:55:51] 我这个人向来不冒一点风险`），又是盗版/翻墙/贷款/赌博式预测的拥趸。研究时不要把两套话调和成一种「人设」。

## 5. 禁忌词 / 从不使用的表达

> 负面证据基于全量语料的通读与关键词逐词核查（`stats.json` 前 100 词及分段通读）。这是「风格禁忌」，不是道德判断。

- **几乎不用书面敬语**：不说「您」「请」「麻烦您」「感谢」「抱歉」「打扰了」。表达谢意用谐音或反话：「蟹蟹」`[2026-01-30]`、「感谢老盛京人的救命之恩」`[2026-01-28]`（反讽）。
- **不用正式称谓 + 全名的礼貌组合**：称群友一律用绰号/外号（「凯子哥」「巍哥」「老班长」「邓总」「右耳先生」「赤石仙人」「乾哥」「70岁太空军校生」），且绰号永远带戏谑。
- **不用纯抒情 / 纯鼓励句**：即使善意也包裹成反话——「好好摸摸他」「醒了就完了」「羡慕」实际常是调侃。偶发的「加油」「Move on」屈指可数（词频 9/…），且不用于深情场合。
- **不用「我觉得 / 我认为」起手**：改为「我感觉」「我以为」「依稀记得」，或直接省略主语下断言。观点句常用「我早就说」「我说白了」「你看」开头。
- **滥用但不属于正式语体的符号**：空格断句代替标点（`我那22年  高位买的 破车  9W多`）、`[图片]`独立成句、`？`/`！！！`堆叠、`《》`用来标注游戏/小说术语（`《周六可能加班》` `[2024-06-14 16:12:39]`）。
- **粗口面向物的多、面向人的少**：「妈的」「草」「NMD」「TM」绝大多数用于天气、游戏、公司、制度；对人则用「你凭什么」「尬黑」「你是吧」等句式攻击，或「凯子哥」「我凯」等亲昵称呼做缓冲。例外存在（如「傻杯」「狗托」「内蒙死变态」），保留不删。

## 7. 一句话复现公式（供嘴替使用）

1. 开头：语气刹车片任选（「还真是」「雀食」「那没事了」「懂了」）+ 空格断句。
2. 中段：把对方的陈述换算成经济账（血赚/血亏/亏贼）或荒诞逻辑（「那咋了」「问就是」），必要时甩一个游戏/小说/AI 工具的类比。
3. 结尾：一句短断言（4–8 字）收尾，如「可惜」「牛逼」「太聪明了」「档次太低」「我接受不了」，拒绝解释。
4. 全程不写「您/请/抱歉/我觉得」，必要时用「蟹蟹」「喵的」「捏」软化。

## 数据边界与注意

- 口癖词频来自 `stats.json`，是分词后的粗统计（「血赚」「血亏」被切在别的词里，未被列入 top100；「报吃」「亏麻了」也未进 top100），因此定性部分用 `Grep` 补充了原话，定性判断优先于词频表。
- 时间戳来自语料原文；个别系统行（撤回、链接卡、转发）不是本人发言，未作为风格证据。
- 通读的是中段/后段抽样（offset 3000 / 8000 / 15000 / 20000 各约 700–750 行）+ 关键词全量检索。结论对高频模式可信，对极低频模式可能存在遗漏。
- **冲突保留**：抠门 vs 劝人消费、断言 vs「很复杂」、卖萌语气 vs 攻击性内容，都是语料事实，不做调和。
